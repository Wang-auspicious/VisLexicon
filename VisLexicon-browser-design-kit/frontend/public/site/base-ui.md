## Overview

Radix、Floating UI 与 Material UI 创作者推出的无样式 React 组件库，通过 npm 包 @base-ui/react 提供可组合的无障碍原语，不捆绑 CSS、不指定样式方案；仓库采用 MIT 许可，文档写明可免费商用。

## Do's and Don'ts
