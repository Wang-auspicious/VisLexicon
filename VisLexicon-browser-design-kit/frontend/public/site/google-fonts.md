## Overview

Google 的免费字体目录，站内可筛选并预览约 1946 个字族。Inter 等字族以 SIL Open Font License 1.1 发布；各字族许可须打开对应 License 页核对。

## Do's and Don'ts

- 许可不是通用宽松协议，逐条确认条款后再使用。OFL-1.1：Inter OFL.txt 写 This Font Software is licensed under the SIL Open Font License, Version 1.1，Copyright 2020 The Inter Project Authors。该 OFL 覆盖 Inter 字族；目录中其他字族许可可能不同，须打开对应 License 页核对。不能把整个 Google Fonts 目录当成单一 MIT。
- 许可原始记录 OFL-1.1：Inter OFL.txt 写 This Font Software is licensed under the SIL Open Font License, Version 1.1，Copyright 2020 The Inter Project Authors。该 OFL 覆盖 Inter 字族；目录中其他字族许可可能不同，须打开对应 License 页核对。不能把整个 Google Fonts 目录当成单一 MIT。（证据：https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt）
