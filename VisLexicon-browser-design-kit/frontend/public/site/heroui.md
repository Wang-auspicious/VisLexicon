## Overview

原 NextUI，YC S24 开源 React 组件库，把 React Aria 与 Tailwind CSS v4 拼成无障碍组件，npm 包 @heroui/react；核心包 MIT，HeroUI Pro 模板另售。

## Do's and Don'ts

- 存在付费层：Core @heroui/react is free MIT; HeroUI Pro templates are a separate paid offering。
- 许可登记为 MIT（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 MIT：packages/react/package.json 的 license 字段为 MIT；npm @heroui/react 3.2.4 亦标 MIT。该 MIT 覆盖 @heroui/react 包。仓库默认分支 v3 根 LICENSE 现为 Apache-2.0，heroui-native 亦为 Apache License 2.0，二者不在本条 React 包范围内；亦不覆盖 HeroUI Pro 模板。（证据：https://github.com/heroui-inc/heroui/blob/v3/packages/react/package.json）
