## Overview

Yahoo! Inc. 发起的 CSS 模块集 Pure，现为 v3.0.0。仓库 LICENSE 标 BSD-3-Clause，不是 MIT。在 Normalize.css 上提供网格、按钮、表单、菜单等模块。

## Do's and Don'ts

- 许可登记为 BSD-3-Clause（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 BSD-3-Clause：LICENSE 为三款 BSD：保留版权声明、二进制再分发须附带声明、不得用 Yahoo! Inc. 名称背书。package.json license 为 BSD-3-Clause。README 写 Yahoo! Inc. BSD-3-Clause license。页脚写 Yahoo BSD License。该许可覆盖 Pure CSS 源码；CREDITS.md 中 Normalize.css 另标 MIT。（证据：https://raw.githubusercontent.com/pure-css/pure/main/LICENSE）
