## Overview

Shopify 统一 UI 框架的开发者文档入口，现托管在 shopify.dev；面向 App Home、Admin、Checkout、Customer accounts 与 POS 等应用表面的 Web Components。当前 Web Components 未开源，旧版 React 库已归档。
