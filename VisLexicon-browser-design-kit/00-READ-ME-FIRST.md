# VisLexicon（视元）浏览器设计代码库

这是一个专门用于上传到浏览器 AI 的精简代码库。它保留了当前前端、产品与内容规格、真实内容样本和页面截图，同时省略采集器、测试、历史会话以及体积巨大的完整生成数据。

## 当前任务授权

本轮明确允许重新设计页面布局、信息架构、视觉系统和响应式行为。旧工程中曾经出现过的“布局冻结”仅是早期开发阶段的工作约束，不限制本轮设计探索。

内容事实仍受以下约束：

- 不得虚构网站、术语、数量、截图、证据或来源链接。
- `candidate` 不能伪装成已经人工审核并发布的内容。
- 网站条目的设计必须容纳身份、范围、事实证明三类证据及三张有效截图。
- 分类、标签与事实证据是不同维度，不要为了视觉整齐将它们混成一个字段。
- 桌面端与移动端都要成立，并保留键盘操作、可读对比度和减少动态效果等无障碍考虑。

## 产品结构

当前顶层有四个频道：

- 策展：高质量外部网站、资源与案例的人工策展入口。
- 图鉴：视觉和交互术语、活舞台、参数与代码导出。
- 工具：辅助比较、检索和生成设计规格的工具。
- 提交：把术语、组件、观察线索或网站整理成可审核草稿。

真正需要设计的不是一个普通导航站，而是“人和设计 Agent 共同使用的视觉知识与选择界面”。用户应该能够逛、找、缩小选择范围，理解一个设计概念，并把结果带入后续设计或开发工作。

## 生产数据规模与本包样本

- 生产态 Visual Atlas：1,932 个术语，来自 27 个来源；其中 1,926 个候选、6 个已发布。
- 当前 9 个活舞台共有 170 个唯一已路由术语认领。
- 本包 `frontend/src/data/visual-atlas.json`：220 条代表性数据，完整保留全部 170 个舞台认领术语，并增加 50 条未入台样本，因此前端舞台仍可运行。
- 原网站候选语料：8,684 条。
- 本包网站目录只放入 12 个经过真实探索和独立复核的 v3 内容包，适合用于设计真实卡片、详情和证据呈现。

样本数量不能当成正式站点总数，页面文案也不要把 12 或 220 写成生产总量。

## 代码入口

- `frontend/src/App.jsx`：导航和路由装配。
- `frontend/src/views/IndexView.jsx`：策展首页。
- `frontend/src/SiteCatalog.jsx`：完整资源目录浏览器。
- `frontend/src/views/Atlas.jsx`：图鉴工作台。
- `frontend/src/stages/`：九个可交互舞台及人工维护的 manifest。
- `frontend/src/App.css`：全站主要样式。
- `frontend/src/atlas.css`：图鉴专用样式。
- `frontend/src/index.css`：基础样式和字体入口。

## 本地预览

在 `frontend` 目录执行：

```powershell
npm install
npm run dev
```

这个副本使用精简后的真实样本数据。原项目和生产数据没有被修改。

## 期望设计输出

先完成信息架构与关键用户路径，再给出桌面和手机方案；随后定义页面模块、内容字段、交互状态和设计系统，最后再改代码。任何删减、合并或重新命名都要说明它解决了什么用户问题。
