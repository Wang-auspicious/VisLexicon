# VisLexicon · 视元

让看见的灵感，变成说得清、找得到、用得上的视觉语言。

设计资料并不稀缺，难的是需要时找得到，也能说清自己喜欢什么。视元因此把站点策展、交互图鉴和生图提示词放在一起，让灵感有出处、效果可预览、方法可复用。

这是一个用于交流想法的早期 Demo。我们希望它逐渐成为人与 AI 共享的视觉词典，缩短从「我喜欢这个」到「我能实现它」的距离。

## 里面有什么

- **策展**：按场景、交付物、技术栈等维度收录的网站与工具，每条都留着出处和核验记录。
- **图鉴**：把动效、排版、布局、材质拆成一条条可检索的效果，点开就能看到它在动。
- **提示词**：把「我喜欢这个」翻成模型能执行的描述，随手复制。

三部分共用一个检索入口，也可以直接用中文口语描述你要的效果。

## 本地运行

Node.js 22.12+。

```sh
npm ci
npm run dev
```

构建与预览：`npm run build` → `npm run preview`。

检索需要 Jev：运行前设置 `OPENCODE_API_KEY`。未配置或 Jev 暂不可用时仍可浏览已发布内容，但检索会明确提示不可用，不会把本地关键词匹配当作 Jev 结果。
