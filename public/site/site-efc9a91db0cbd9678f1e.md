## Overview

Kibo UI 是面向 shadcn/ui 的开源组件注册表，首页可浏览 41 个组件、28 个 Blocks 和 1101 个 Patterns。组件页列出 Color Picker、Image Zoom、QR Code、Code Block、Dropzone、Marquee 等，并给出 npx kibo-ui add 安装命令；Blocks 提供 Form、Roadmap 等预组合区块。
