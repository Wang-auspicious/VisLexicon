## Overview

把 Semantic UI 的样式包成 Angular 2 指令的仓库，模板里写 sm-segment 这类标签就能出效果。README 要求自己下载 Semantic UI 的 css 与 js、再连同 jQuery 一起塞进 angular-cli.json，最后一次提交已是十年前。
