## Overview

Opensource UI 提供可复制粘贴的 React/Next.js 组件源码，页面含实时预览与代码区，覆盖按钮、表单、表格、加载器、社交卡片、音频播放器、渐变背景，以及 iPhone、MacBook、Apple Watch、iPod、浏览器框等设备样机。组件以 TypeScript 编写、用 Tailwind CSS 样式，复制后可直接改 props 与样式。

## Do's and Don'ts

- 许可登记为 MIT（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 MIT：组件以 MIT 许可发布，可用于个人与商业用途。（证据：https://opensourceui.in/）
