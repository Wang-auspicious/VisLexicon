## Overview

CFCs（Cross Framework Components）是 NAVER 开源的一套写法，按你熟悉的框架习惯写一次组件，就同时支持 React、Vue@2、Vue@3 与 Svelte，不必为每个框架复制代码。全库 TypeScript 写成，另提供 CFCs Reactive 这种不产出 UI、只管状态的多框架工具组件。
