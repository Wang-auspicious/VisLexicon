## Overview

Svelte 5 的数据表格组件，用几行代码接入后自带排序、表头筛选、单元格内编辑、虚拟滚动与分页，并可配合 RestDataProvider 把 CRUD 直接打到服务端。MIT 授权，也提供 React 与 Vue 版本。
