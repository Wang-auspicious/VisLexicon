## Overview

ol-cesium 是 OpenLayers 与 Cesium 的集成库，提供在二维地图与三维地球之间切换与联动的代码实现，交付可嵌入的 JavaScript 模块与示例。其实际特性包括支持 OpenLayers 图层与 Cesium 场景同步、提供同步查看器组件，便于在 Web 地图应用中组合二维和三维可视化能力。
