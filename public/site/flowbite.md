## Overview

Flowbite 为 Tailwind CSS 项目提供组件与 JavaScript 行为文档。官方介绍页说明接入、暗色模式和类型支持，并按集成框架组织资料；Accordion 页解释折叠状态与 data 属性，Buttons 页展示多种实际按钮颜色和对应 HTML。适合把常用控件组合进界面，设计文件、区块和 Pro 产品的范围与取得条件仍应分别核对。
