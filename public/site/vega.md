## Overview

Vega 用声明式 JSON 描述可视化外观与交互，再由 JavaScript 运行时生成 Canvas 或 SVG 视图。官网连接数据变换、比例尺、坐标、图例和图形标记，Example Gallery 按图表类型列例子。Bar Chart 原例完整显示八根柱及坐标，下面连接 JSON 规范与在线编辑器；本轮没有测试 hover 提示，也不把关联 Vega-Lite 或 Altair 并入同一入口。
