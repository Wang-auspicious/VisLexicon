## Overview

creative-ui 是 Krutik Raut 维护的 shadcn 注册表，提供 14 个 React 组件与 2 个 Claude skills。组件涵盖 DNA Carousel、Rotunda Carousel、Tear Reveal、Wax Seal、Image Trail、Dithering Hover、Marbled Paper、Gold Leaf、Etching、Cyanotype、Masked Collage Frame、Duotone & Print Filter、Grain & Paper Overlay、Halftone Image；skills 包括 Classical Collage Web Design 与 Lasting Logo Design。可通过 shadcn CLI 按名称或 JSON URL 安装，文件写入项目后为可编辑的 React 与 Tailwind 代码。
