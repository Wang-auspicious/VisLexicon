## Overview

React Native Gesture Handler 是一个声明式 API，将平台原生触摸与手势系统暴露给 React Native 使用。它提供对原生手势识别的直接访问，并附带全新的 Touchable 组件，该组件可完全自定义，用于替代 Pressable 和 Button，支持原生缩放、透明度、底层和 Android 波纹反馈。
