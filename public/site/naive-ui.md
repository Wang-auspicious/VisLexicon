## Overview

Naive UI 提供 Vue 3 组件套件，首页说明主题可调和 TypeScript，文档分别介绍安装、按需引入、主题与 SSR 集成。Button 页面把 Basic、Secondary、Tertiary 和 Quaternary 变体并列，能比较同套状态颜色、形状和文字按钮。安装页明确只支持 Vue 3，图标与字体资源需按各自依赖另外配置。
