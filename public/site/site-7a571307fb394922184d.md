## Overview

Lisse 是一套用于 Web 的 Figma 级 squircle（平滑圆角）渲染方案，以 @lisse 包系列形式提供。其名称源自法语 lisse（光滑），核心交付物为可生成视觉连续、无方向突变的平滑曲线圆角渲染代码，适用于需要高质量圆角视觉一致性的 Web 界面实现。
