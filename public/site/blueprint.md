## Overview

Blueprint 为 Web 上的数据密集界面提供 React 工具包。官方文档说明 @blueprintjs 各包的安装、组件导入和 CSS 接入，范围涵盖 Core、Datetime、Icons、Select 与 Table；Button 页展示基础按钮、JSX 用法和更多外观选项。适合从成套组件与数据界面控件建立应用，安装时需要同时核对包依赖和样式文件。
