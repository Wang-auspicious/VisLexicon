## Overview

ThreeTools 是一枚 Chrome 扩展形态的 Three.js 场景检查器，给写 Three.js 与 React Three Fiber 的人用：装在浏览器里就能打开任意线上项目的场景图，实时改位置、旋转、缩放、材质、相机和灯光。
