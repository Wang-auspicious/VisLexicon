## Overview

把 Bootstrap 5 的组件接进 Svelte 4+ 的组件库：不用写 Bootstrap 的组件 class、不引它的 JavaScript、也不依赖 jQuery，但 CSS 需要自己另引一份 Bootstrap 5。MIT 授权，灵感来自 React 的 reactstrap。
