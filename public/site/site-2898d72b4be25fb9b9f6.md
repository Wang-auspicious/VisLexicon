## Overview

Underscore.js 是一个 JavaScript 工具库，提供函数式编程辅助功能。它交付一组独立函数，涵盖集合迭代与转换、数组操作、对象操作、函数绑定与节流等常见任务。实际特性包括：支持链式调用语法以组合操作；不扩展任何原生 JavaScript 对象；处理集合时同时返回数组和对象结果。库体积小，可单独使用或与 Backbone.js 等框架配合。
