## Overview

Fontsource 上 Cascadia Code 的字体页，等宽编程字体，Extra Light 200 到 Bold 700 共 6 档，带 Italic (ital) 与 Weight (wght) 可变轴。写代码界面或终端面板时可以拿它做自托管字体。
