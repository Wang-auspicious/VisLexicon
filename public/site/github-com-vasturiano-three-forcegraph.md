## Overview

three-forcegraph 是一个将力导向图渲染为 ThreeJS 3D 对象的 JavaScript 库，交付可嵌入网页的 3D 图可视化组件。它基于 d3-force 进行物理模拟计算，并将节点与连线映射为 ThreeJS 几何体，支持在三维空间中旋转、缩放和交互查看关系网络。
