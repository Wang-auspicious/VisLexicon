## Overview

Dray 是一个 macOS 应用，把 Claude Code、Codex、pi、fx、Grok 等编码代理集中到同一窗口运行。页面提供 macOS 安装包下载，并说明可在 Mac mini 或 VPS 上通过 install.sh 运行远程服务器；应用内可并行编排多个代理会话、查看 PR 检查与评审、用浏览器标签运行并检查自己的 UI 工作。
