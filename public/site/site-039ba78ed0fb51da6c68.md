## Overview

NexUI 提供可直接复制进项目的 React + Tailwind CSS 组件，组件页按 Auth、Calendar、Carousel、Charts 等分类列出 102 个组件，每个组件带 Preview 与 Code 切换。也可用 CLI 执行 init 初始化 nexui.config.ts、lib/utils.ts 与 globals.css，再用 add 把 button、card、badge 等单个组件文件写入 components/ui。
