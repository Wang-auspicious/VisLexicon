## Overview

Cubby UI 提供基于 React、Tailwind CSS 与 Base UI 的界面组件，首页可预览 Text Morph、Circular Slider、QR Code、Transition Panel、Filters、Code Block、Marching Border 等真实组件，并给出 npx shadcn@latest add @cubby-ui/... 的单组件安装命令；组件页可复制源码，源码会复制进项目而非作为依赖。
