## Overview

Maizzle 是一个用于开发、预览和构建生产级电子邮件的框架，基于 Vue 和 Tailwind CSS 提供现代开发环境。它支持作为独立工具或集成到 Vite 项目中，可通过命令行调用，并输出适配邮件客户端的 HTML。
