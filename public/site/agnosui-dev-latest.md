## Overview

AgnosUI 是一套框架无关的组件工厂，同一份 TypeScript 工厂同时给 Angular、React、Svelte 生成无样式组件，另外单发一份 Bootstrap 皮肤。版权方是 Amadeus，整库 MIT。
