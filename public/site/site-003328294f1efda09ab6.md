## Overview

devl 提供 277 个免费 React 组件、区块与整页界面，基于 coss ui（Base UI 与 Tailwind）。每个条目是单个 TypeScript 文件，可复制源码、用 shadcn CLI 安装，或复制提示词交给 AI 编辑器。目录按 Liquid、Conversation、Forms、Charts 等 16 类组织，另有 Motion 与 Illustrations 分区。
