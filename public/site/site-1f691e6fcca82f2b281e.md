## Overview

Motion-Primitives 提供可复制粘贴的动画 UI 组件文档，涵盖 Accordion、Animated Background、Animated Group、Carousel、Cursor、Dialog、In View、Infinite Slider、Transition Panel 等核心组件，以及 Text Effect、Text Loop、Text Morph、Text Roll、Text Scramble、Text Shimmer 等文字动效和 Animated Number 数字动效。页面说明其面向 React、Next.js 与 Tailwind CSS，可自定义并开源。
