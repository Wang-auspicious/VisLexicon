## Overview

CSShake 用命名 CSS 类为 DOM 元素加入摇晃效果。官网列出基础、缓慢、水平、垂直和旋转等类型，下载中心分别提供完整包、单项样式及压缩文件；How to use 区直接给出样式链接、元素类名和 shake-trigger 的写法。适合为已有元素选取短小动效，定制幅度和节奏可继续查 Sass mixin，而实际运动效果应另行测试。
