## Overview

shadcn-cssinjs 是一个基于 Base UI 原语、用 StyleX 重新样式化的 shadcn/ui 组件注册表。首页提供 pnpm dlx shadcn add 命令，可把 accordion 等组件 JSON 安装到项目；文档区列出 Accordion、Alert、Button、Calendar、Card 等组件条目，并说明可通过在 URL 后加 .md 获取 Markdown 版本。
