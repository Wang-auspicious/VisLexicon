## Overview

Melt UI 为 Svelte 提供不预设样式的组件 builders，把行为和属性交给自己的界面元素。引言展示 Builder API，目录覆盖 Accordion、Calendar、Combobox、Dialog 等；Accordion 示例同时呈现展开内容和折叠项。入口还连接带 Runes 的新版本，采用时应区分目标版本与 builder 接口。
