## Overview

codeowners-generator 让 monorepo 里可以到处放 CODEOWNERS 文件，再编译成一份 GitHub 认得的合并文件，也能读 package.json 的 maintainers 字段。

## Do's and Don'ts

- 许可登记为 MIT（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 MIT：右侧 About 栏与 README 标签行都写 MIT license（证据：https://github.com/gagoar/codeowners-generator）
