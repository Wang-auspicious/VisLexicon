## Overview

Tremor 提供构建数据界面的 React 组件，将图表、输入、过滤与辅助控件组合为仪表盘采用起点。官网明确 Tailwind CSS、Radix UI 和 Recharts 的关系，Installation 连接框架采用与其他资源，Donut Chart 原例完整显示有限环形图。可按数据任务选控件或模板；第二个 pie 例子底部未入画，Premium blocks 和组件的权益不能合为一项。
