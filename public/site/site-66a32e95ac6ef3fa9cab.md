## Overview

SpreadJS 是 Mescius 旗下基于 HTML5 的 JavaScript 电子表格控件，提供类 Excel 的表格渲染、公式计算、数据绑定与导入导出功能。支持在 Web 应用中嵌入电子表格界面，兼容 Excel 文件格式，并可通过 API 自定义单元格类型、图表与数据验证等交互行为。
