## Overview

react-native-pie-chart 是面向 React Native 应用的开源饼图模块，提供可嵌入移动界面的饼图组件，便于在 iOS 与 Android 项目中直接集成数据可视化能力。该项目以源码仓库形式交付，支持安装后按组件方式调用，并可通过 GitHub 参与贡献与问题反馈。
