## Overview

PixKit 是一套像素画风格的 UI 组件库，同时供 React 与 React Native 用，仓库是 monorepo，拆成 @pixkit/react、@pixkit/native、@pixkit/tokens 三个包，另有一个网页版 Live Demo。
