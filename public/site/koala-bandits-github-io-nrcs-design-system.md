## Overview

为合作伙伴 NRCS 做的设计系统，是 FPAC Design System 的改版，而 FPAC 又源自美国联邦政府的 U.S. Web Design System。组件按 Default 与 Small 两档尺寸各出一套，涵盖大部分 FPAC 组件与几个自定义复杂组件。
