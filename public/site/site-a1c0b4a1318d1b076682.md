## Overview

pdfcn 提供可直接用于 React 的 PDF 组件与区块，首页展示 corporate-invoice、financial report、minimal invoice 等文档模板，并可切换 Preview/Code 查看。组件通过 shadcn 命令安装，例如 pnpm dlx shadcn add @pdfcn/forme/alert，也可复制给 agent 的 prompt；另有 Theme Builder 与 Takumi、Forme 组件文档。
