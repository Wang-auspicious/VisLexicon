## Overview

开源文档编译器：一份 Markdown 源文件，一条 npx @docmd/core dev 命令，同时产出网站、本地向量检索索引和给 AI agent 用的 MCP 上下文。

## Do's and Don'ts

- 许可登记为 MIT（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 MIT：首屏数字块写着 100% Open Source (MIT)（证据：https://docmd.io/）
