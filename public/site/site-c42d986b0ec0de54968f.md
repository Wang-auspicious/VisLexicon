## Overview

Shiori 是一个基于网页的内容收藏与阅读管理工具，用户可保存阅读、观看或想记住的内容，并自动捕获正文、转录文本和摘要以便日后检索。支持通过 Chrome 或 Edge 安装为 Windows 渐进式 Web 应用（PWA），提供搜索、收藏夹、信息源订阅和标签管理功能，并支持 Apple、Google 或邮箱注册登录。
