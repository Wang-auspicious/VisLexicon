## Overview

建在 Ark UI 原语上的一套产品界面组件，用 CSS Modules 写样式，同时给两条获取路径：装 npm 包，或者通过 shadcn 风格的 registry 把组件源码拷进自己的项目。已发布的适配器是 React 和 Solid，Vue 与 Svelte 还在计划里。
