## Overview

Aceternity UI 主要提供可复制到 React 项目的界面组件和页面区块，首页还连接模板入口。组件目录中的 Chromatic Image、Cloud Shader 和 Text Flipping Board 展示不同视觉效果；3D Card Effect 页给出卡片预览、代码切换与安装入口。适合挑选落地页片段后按项目修改，具体条目的取得方式和授权仍应查看其直接页面。
