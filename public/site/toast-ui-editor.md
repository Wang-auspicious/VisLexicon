## Overview

TOAST UI Editor 把 Markdown 文本编辑、渲染预览与 WYSIWYG 模式放在一个可嵌入编辑器里，官网列出语法高亮、滚动同步与插件能力。API 和 Examples 分开组织采用范围，Basic 原例完整显示工具栏、Markdown 输入与右侧预览，以及两个模式入口。可按文档需要选择模式与插件；图里的星数和原始介绍文属于样本内容，切换和同步没有在本轮执行。
