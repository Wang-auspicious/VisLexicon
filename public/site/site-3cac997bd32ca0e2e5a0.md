## Overview

Ghostex 是一个原生多智能体工作台，把 Agent 聊天、代码编辑器、浏览器、终端和 Kanban 板放在同一窗口里。页面提供 macOS、Windows、Linux、Android、iOS 下载入口，并展示用 Claude Code、Codex 等 CLI 会话并行改代码、跑测试、在浏览器里标注页面后回传 Agent 的操作示例。
