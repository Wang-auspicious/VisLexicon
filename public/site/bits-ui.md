## Overview

Bits UI 为 Svelte 提供无预设样式的界面原语，开发者可按自己的设计系统安排外观。文档按 Accordion、Alert Dialog、Calendar、Combobox 等组件组织，并提供状态管理和样式说明；Accordion 页面把三项折叠内容与 Svelte 导入代码放在一起，适合从具体控件开始接入。
