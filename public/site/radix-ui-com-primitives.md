## Overview

Radix Primitives 提供由开发者自行配样式的 React 基础组件，首页以 Dialog、Dropdown Menu 和 Popover 展示核心控件。文档说明无障碍、样式、组合与服务端渲染，并逐项组织组件 API。Dialog 示例打开后呈现 Name、Username、保存和关闭控件，页面附模态模式与焦点管理说明。适合把底层交互能力接入自己的设计系统。
