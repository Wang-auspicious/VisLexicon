## Overview

Svelte 里做可访问排序列表的包，键盘、鼠标、触屏拖拽都支持，组件 API 是 <SortableList.Root> 这一族，另带屏幕阅读器播报。v2.x 配 Svelte 5，v1.x 配 Svelte 4。
