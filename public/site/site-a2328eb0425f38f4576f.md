ForgeUI 提供可复制粘贴的 shadcn/ui 风格 React + Tailwind 组件与页面区块，首页可进入 Components、Blocks、Illustrations、Templates 等入口；区块页按 Header、Hero、Pricing、FAQ 等分类浏览，并提供 header01、header02 等预览链接。Pro 版宣称含 250+ UI 区块、10 个 Next.js + Tailwind 模板及 Framer Motion/GSAP 动画。
