## Overview

Bootstrap 把栅格布局、组件样式和 JavaScript 插件放在同一套工具包中。这个官方入口给出 npm 安装、CDN 引入与 Sass 定制入口，文档可查布局和组件用法，示例区可预览并下载页头、首屏、侧栏、下拉菜单、列表与模态框等页面片段。适合用 HTML、CSS 和 JavaScript 搭出可继续修改的网站基础。
