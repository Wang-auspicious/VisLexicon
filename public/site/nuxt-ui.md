## Overview

Nuxt UI 提供带类型、主题与配套图标等集成的 Vue 界面组件，官网说明它基于 Reka UI 和 Tailwind CSS。目录覆盖布局、表单、数据、导航与浮层；Button 文档将原绿色按钮与完整的 UButton 默认插槽示例并列，也说明 label 属性。可按 Nuxt 或普通 Vue 项目读对应指南，模板与单个组件的采用范围分开核对。
