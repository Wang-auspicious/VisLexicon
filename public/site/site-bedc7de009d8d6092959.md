## Overview

Velora UI 提供可经 shadcn CLI 安装的动画 React 组件与区块，首页列出 Marquee、Globe、Morphing Text、Border Beam、Dock、3D Card 等条目及体积与依赖信息，并可按 Backgrounds、Text、Buttons、Cards & Layout 等分类浏览；另有 31 个整段区块与落地页模板入口。
