## Overview

Orbkit 提供 95 个用于 AI 与语音 Agent 状态的 WebGL 着色器光球，以 React 组件形式通过 shadcn registry 安装到本地代码。首页列出 SHDR-01 至 SHDR-33 等编号并附 npx shadcn add 命令；Playground 可切换 Idle/Thinking/Speaking 状态、调整 Tint 颜色、尺寸、Speed 与 Spin 参数，并复制状态到其他两个状态。
