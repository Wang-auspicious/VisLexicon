## Overview

Svelte 的可拖拽分栏组件，用一组小部件拼出可调整大小的布局，支持嵌套分组、CSS 定制，以及把布局存进 LocalStorage 或 cookie 里下次还原。README 说明思路来自 react-resizable-panels，是它的 Svelte 版本。
