## Overview

ColorBrewer 2.0 用于为分级地图选择配色。用户可按顺序、发散或定性数据选方案和类别数，地图会展示对应颜色分布，并给出 HEX 等色值及色盲、打印条件筛选。官网还列出 ASE、GIMP、JavaScript 与 CSS 导出方式。适合先根据数据关系比较配色，再把选择带入制图项目；不同参数 URL 表示同一工具的实际配置状态。
