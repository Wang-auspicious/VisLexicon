## Overview

Pure 用较小的 CSS 模块为原生 HTML 元素与常用界面控件提供样式，官网按 Base、Grids、Forms、Buttons、Tables 和 Menus 组织采用范围。Get Started 说明引入与模块方式，Buttons 页完整比较链接与按钮元素的默认样式、禁用样式和对应代码。可以只采用需要的模块，再在其上写项目样式；体积宣传不是本轮测量。
