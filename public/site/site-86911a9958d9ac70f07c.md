## Overview

Glassy UI 提供 38 个免费 React 玻璃质感组件，可通过 shadcn CLI 安装或直接复制源码到项目。组件涵盖按钮、输入框、对话框、菜单、Dock、Lens、Scene 等，并提供 React Native 版本。页面还展示玻璃折射、模糊与动效演示，以及可编辑的组件文件结构。
