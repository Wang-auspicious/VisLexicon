## Overview

Ruru UI 提供可安装的 React UI 组件与区块：通过 npx ruru-ui-cli init 初始化项目，再用 add 命令选择 button、input、tabs、modal 等组件；Blocks 页可预览 login-1、register-1、forgot-1 等预构建页面区块，并查看代码。文档还列出 Accordion、Avatar、Badge、Checkbox、Dropzone、Form 等组件及主题、动画、Hooks 说明。
