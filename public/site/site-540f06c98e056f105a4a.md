## Overview

webclaw 提供面向 LLM 与 AI Agent 的网页抓取 API，可将公开网页转换为 Markdown、JSON、纯文本或原始 HTML，并支持结构化字段提取。页面还提供 CLI、MCP Server 与自托管方式，演示区可粘贴 URL 查看模型将读取的内容，并列出抓取、搜索、映射、爬取与监控等端点。
