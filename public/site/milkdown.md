## Overview

Milkdown 是用于构建所见即所得 Markdown 编辑器的插件框架，语法、主题和界面可通过插件扩展。指南用 @milkdown/crepe 的安装和初始化代码给出起点；Playground 并排展示 Markdown 源文与渲染内容，包含引用、图片和代码。它适合在自己的应用中嵌入编辑体验，协作仍需按文档集成。
