## Overview

Chartkick.js 是一个用单行 JavaScript 创建图表的开源库，交付物为可引入网页的图表脚本文件。它支持多种图表类型并兼容主流 JavaScript 图表引擎，通过简洁 API 减少样板代码，适合快速在页面中嵌入数据可视化。
