## Overview

Handoff 是一个面向人与 AI Agent 的共享上下文工作区：可创建 Space，用带自定义字段的 Item 和 depends_on、references、blocks 等语义边组织知识，并在树状或交互式 3D 画布中浏览。页面还展示可配置 Agent 的实时聊天、工具调用记录、变更历史与一键回退，以及通过 MCP 接入 Claude、ChatGPT、Cursor 等客户端。
