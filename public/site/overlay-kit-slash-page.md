## Overview

React 的浮层管理库，把弹窗、抽屉这类浮层的开关写成一个 overlay.open() 调用，免掉 useState 与 onClose 那套状态管理。站点只有 Documentation 与 API 两栏，加一个 Ctrl K 搜索入口。
