## Overview

Cropper.js 是可嵌入页面的 JavaScript 图像裁剪控件。2.x 指南说明它由多个 Web Components 组成，提供按需导入与多个选区等能力；API 页面用海景图显示带网格和控制点的裁剪选区，并列出 Canvas、Image、Selection、Viewer 等元素。接入时应区分 1.x 与 2.x 的结构和接口。
