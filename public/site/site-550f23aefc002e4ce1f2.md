## Overview

PaceUI 提供可复制到 Next.js 与 TanStack Start 项目的动画 React 区块、组件和模板，页面列出 394 个 Blocks + Charts、95 个 Components、17 个 Crafts 与 7 个 Templates，并可按 Stats、Charts、Widget、Tables 等仪表盘区块浏览。官方还提供 MCP Agent Server，让 Cursor、Claude 或 Windsurf 发现并插入 UI 区块。
