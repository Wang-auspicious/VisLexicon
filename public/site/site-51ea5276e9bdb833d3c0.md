## Overview

Space UI 提供可安装的交互式 UI 组件与区块：首页给出 pnpm dlx shadcn@latest add @spaceui/essentials 安装命令，组件页列出 Avatar、Accordion、Slider、Switch 等条目，另有 Primitives、Blocks、Templates 与 Hooks 分区，以及 UI Avatars、Flags、Image Split 等工具入口。
