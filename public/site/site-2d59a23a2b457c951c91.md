## Overview

OpenCode 是一个开源 AI 编码代理，可在终端、桌面应用或 IDE 扩展中运行，帮助编写和运行代码。页面提供 curl、npm、bun、brew 等安装命令，并说明可连接 Claude、GPT、Gemini 等 75+ 模型提供商或本地模型，也支持用 GitHub Copilot 或 ChatGPT Plus/Pro 账户登录。

## Do's and Don'ts

- 许可登记为 MIT（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 MIT：官方 FAQ 称源码在 GitHub 上以 MIT 许可证公开。（证据：https://opencode.ai/）
