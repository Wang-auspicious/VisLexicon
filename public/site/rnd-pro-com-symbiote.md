## Overview

基于原生 Custom Elements 的 UI 库，核心主张是 Runtime Agnostic Templates（RAT）：模板只是一段带命名绑定的 HTML 字符串，与组件实例、渲染函数和运行时解耦，不需要虚拟 DOM 或强制构建步骤。页面还把「Agentic Web 与 WebMCP」列为它的第四条设计理由。
