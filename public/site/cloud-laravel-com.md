## Overview

Laravel Cloud 是官方出的托管云，把 Laravel 应用的构建、部署、数据库、缓存、对象存储和 WebSocket 都接过去，每个 PR 还会自动开预览环境。首页按 Deploy、Run、Scale 三段讲，另有一个私有云版本。
