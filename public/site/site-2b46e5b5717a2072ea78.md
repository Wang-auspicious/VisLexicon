## Overview

Distill 是一款本地优先的笔记与思考空间应用，提供 Windows 桌面版和 iOS 移动端。页面展示可捕获文字、链接、照片与截图，并支持语音口述记录；内置可自定义的智能体，能按日程运行任务、整理条目并维护记忆。文档区还列出 Vault、Entries、Lists、Todos、MCPs、Workflows、Agents、Publishing、Sync 与 API 等模块。
