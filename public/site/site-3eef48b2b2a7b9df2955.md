## Overview

Morphrig 是一份关于图标形变（icon morphing）的十部分在线手册，从“形状对计算机意味着什么”讲到如何自行构建。站点提供可拖拽的菜单到叉号形变演示，并附 18 词术语表，按字母或章节索引；文档涵盖 SVG 路径语法、贝塞尔曲线、rig 编写、导入 Lucide/Tabler 图标、编译零 JavaScript 切换及 React 组件等具体章节。
