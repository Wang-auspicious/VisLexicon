## Overview

Caravan UI 是给 Angular + Tailwind 项目用的一套组件库，顺着 Atomic Design 的思路把 Avatar、Button、Slider、Toggle 这类基础组件和 Dialog、FAQ list、Reactive form 这类组合模板都做好了。装法是 npm install @caravancoop/ui-kit，再把包路径写进 tailwind.config.js 的 content 数组。
