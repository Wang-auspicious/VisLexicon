## Overview

Float UI 提供可直接复制粘贴的 Tailwind CSS UI 组件与网站模板，覆盖营销页的 Banner、CTA、Hero、FAQ、Pricing、Testimonials 等区块，以及应用界面的输入框、表格、分页、卡片等。组件可按 HTML、React.js、Vue.js、Svelte.js 切换代码，模板基于 React、Next.js 与 Tailwind CSS，页面还提供 Demo 与 GitHub 入口。
