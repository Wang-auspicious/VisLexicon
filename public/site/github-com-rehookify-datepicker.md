## Overview

一个零依赖的 React 日期选择器行为库，把日历、日期区间和时间选择的逻辑与无障碍实现封装好，再用 prop-getters 把该有的 props 交给使用者的组件去渲染。适合不想自己啃日历状态机的 React 项目。
