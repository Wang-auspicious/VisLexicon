NumberFlow 是一个用于 React 的动画数字组件，页面提供基础用法、Props、样式、分组与 Hooks 文档，并给出可复制的 <NumberFlow value={123} /> 示例。可查看 format、locales、prefix/suffix、trend、digits、plugins 等属性说明，以及通过 ::part 和 CSS 变量定制数字外观的方法。
