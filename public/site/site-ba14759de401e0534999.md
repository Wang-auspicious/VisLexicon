## Overview

Kokonut UI 是一个 React 组件目录，组件基于 Tailwind CSS、Motion 与 shadcn/ui 构建。首页列出 102 个可实时预览的组件，涵盖背景、卡片、导航、输入、AI、媒体、文字与按钮等分类，例如 Apple Activity Card、Detent Dial、Slide to Confirm。每个组件可通过 shadcn CLI 命令或 AI agent 提示安装为仓库内单文件源码，也可将 @kokonutui 命名空间加入 components.json 后按短名引用。
