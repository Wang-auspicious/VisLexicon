## Overview

Icon Foundry 是由 Fresh Contrast 维护的浏览器端图标浏览与搜索工具，聚合托管于 GitHub 的开源图标库。用户可按关键词检索图标并一键复制，支持收藏集管理、Figma 插件接入及快捷键 Ctrl+K 快速搜索，便于设计师与开发者集中查找和取用图标资源。
