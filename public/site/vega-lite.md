## Overview

Vega-Lite 用较精简的 JSON 编码描述数据与图形标记关系，并自动生成坐标、图例和比例尺。Example Gallery 按单视图、组合与交互组织范围，Simple Bar Chart 原例完整显示九根柱和坐标，连接 JSON 规范与在线编辑器。可以从常见图形开始，再使用组合与数据变换；它与底层 Vega 保留各自入口，本轮没有测试拖动选择或完整编译过程。
