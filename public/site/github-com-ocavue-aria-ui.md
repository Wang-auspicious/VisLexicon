## Overview

把无障碍控件做成原生 light-DOM 自定义元素的 monorepo。@aria-ui/elements 出 listbox、menu、popover、tooltip，@aria-ui/core 用 signal 反应式运行时写元素，@aria-ui/cli 生成 React、Vue、Solid、Preact、Svelte 的类型化 wrapper。
