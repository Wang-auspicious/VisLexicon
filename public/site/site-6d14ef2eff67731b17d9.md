## Overview

Toolcraft 是面向设计应用开发的开源起始套件与 UI 组件库，提供滑块、颜色选择器、渐变、曲线、字体选择器、画布、图层、关键帧与工具栏等创作工作区组件，并附带 AI 技能与视觉测试规则。可通过 npx @pixel-point/toolcraft create 初始化项目，用于搭建品牌资产生成器、WebGL 轮播与交互动效等定制小应用。
