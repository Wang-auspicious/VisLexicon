## Overview

Sera UI 是面向 React、Next.js 与 JSX 的开源 UI 组件库，首页列出按钮、表单、卡片、标签页、弹窗、文本特效、背景效果与网站区块等组件入口，并提供 Installation 文档页。页面还列出 Color Palette、Gradient Generator、SVG Icon Library 等工具入口，组件以 Tailwind CSS 样式和 Framer Motion 动画为卖点。
