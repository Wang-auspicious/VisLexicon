## Overview

一个 React 粒子背景组件，作者把 Proton 官网的粒子源码打包成 ParticlesBg，可以按 type 选 circle、cobweb、polygon 等十几种动画，也支持自定义。仓库另给了一个 Vue 版的 particles-bg-vue 地址。
