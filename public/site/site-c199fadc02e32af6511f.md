## Overview

Are.na 是一个用于保存、整理与连接内容的在线平台：可把照片、笔记、文件、网页等保存为 block，放入可编辑、可排列、可搜索的 channel；也可跨频道、网络与全站搜索，并复用已有内容建立新语境。首页还提供 iOS 应用下载、开放 REST API 文档与 SDK/MCP 资源入口。
