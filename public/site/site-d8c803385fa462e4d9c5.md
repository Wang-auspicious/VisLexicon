## Overview

beUI 提供可复制或通过 shadcn CLI 安装的动画 React 组件，涵盖按钮、模态框、Toast、Dock、标签页、图表与 AI 界面组件；另有 72 个基于 Reanimated 的 React Native 组件。页面可浏览组件、Blocks、Agents、Charts 与 Playground，并给出 bunx shadcn add 与 npx beui-native add 安装命令。
