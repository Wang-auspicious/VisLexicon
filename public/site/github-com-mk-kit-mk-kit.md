## Overview

@mk-kit/ui 的仓库：一套可换主题、达 WCAG 2.1 AA 的 Angular 后台组件库，靠 Signals 与 CSS 变量做明暗主题；同一个 monorepo 里还有从组件抽出来的 @mk-kit/core 引擎和 OIDC 相关的 @mk-kit/auth。
