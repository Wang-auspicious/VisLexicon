## Overview

Svelte 的无样式无障碍原语库，站点把它定位成 building your own high-quality component library 的地基。首屏直接摆出四张小组件演示卡，示意这些原语能拼出什么。

## Do's and Don'ts

- 许可登记为 MIT（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 MIT：同一项目的 GitHub 仓库页 README 标题旁与 About 栏写着 MIT license（证据：https://github.com/huntabyte/bits-ui）
