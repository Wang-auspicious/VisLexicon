## Overview

React DnD 为 React 界面提供拖放行为，用 item、type、Hooks 和不同 backend 连接自己的组件。Overview 解释数据与视图的分离，Examples 按目标、嵌套、排序与自定义预览组织；Handles and Previews 原例显示一个带绿方块手柄的拖动项和一个自定图像预览项，并提供 JavaScript/TypeScript 代码入口。
