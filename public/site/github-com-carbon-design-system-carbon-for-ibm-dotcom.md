## Overview

Carbon for IBM.com 是 Carbon 设计系统针对 IBM.com 的扩展库，装的是 IBM.com 各段用户旅程里共用、用来统一观感的组件，拆成 web components、services、styles、utilities 四个包发布，React 侧另有一层 wrapper。给要搭 IBM.com 页面、或想参考大厂 Web Components 组织方式的团队看。
