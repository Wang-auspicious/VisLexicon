## Overview

Sprig 把问卷调研拆给几个研究 agent：Design agent 听一句目标就搭出题组与跳转，Field agent 把问卷变成对话式投放，Synthesize agent 负责把回答整理成结论。投放渠道覆盖邮件、样本库、网站和 App 内 SDK。
