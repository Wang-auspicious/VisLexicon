## Overview

termcn 提供基于 React 的终端 UI 组件库，构建于 Ink 与 OpenTUI 之上，并通过 shadcn 分发。包含布局、排版、输入、图表、模板等组件，支持文档、主题定制与 MCP 注册表，可按需复制安装使用。
