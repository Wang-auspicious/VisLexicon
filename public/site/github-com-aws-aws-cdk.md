## Overview

用代码定义云基础设施的开发框架，把 CloudFormation 的底层资源定义包成更高层的构造器，仓库是 monorepo，主语言 TypeScript，Apache-2.0 许可。

## Do's and Don'ts

- 许可登记为 Apache-2.0（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 Apache-2.0：右侧 About 栏的 Apache-2.0 license 一行（证据：https://github.com/aws/aws-cdk）
