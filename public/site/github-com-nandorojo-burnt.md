## Overview

React Native 上的跨端 toast 与 alert 库，iOS 包的是 SPIndicator 和 AlertKit，Android 用 react-native 的 ToastAndroid，Web 端包了 sonner。README 强调它走原生组件而不是用 React state 自绘 UI。
