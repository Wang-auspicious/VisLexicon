## Overview

FlyonUI 是面向 Tailwind CSS 的开源 UI 组件库，首页提供 80+ 预构建组件示例（如 Accordion、Alert、Avatar、Badge、Button、Card、Input、Tabs），并展示语义类写法与原生 Tailwind 工具类写法的代码对照，可复制使用。站内还链接 Blocks、Templates、Figma 设计系统与 MCP 工具入口。
