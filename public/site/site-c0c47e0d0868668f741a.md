## Overview

这是一个声明式 Web 音频合成库的文档站，首页给出用 npm 安装 @web-kits/audio 的命令，并展示用 defineSound 定义正弦波音源、包络与增益后调用播放的示例。Library 页列出 Retro、Mechanical、Core、Minimal、Crisp、Organic、Soft、Playful、Drums、Synths 等可查看的声音补丁。
