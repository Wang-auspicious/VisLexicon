## Overview

Canvas UI 提供 35 个基于 HTML-in-Canvas 的创意组件，如 ASCII Object、Blaze、Glass、Particle Reveal 等，每个效果同时提供 WebGL 与 WebGPU 构建。可浏览组件库、在 Playground 预览，并通过 shadcn CLI 命令把完整源码复制进项目，支持 React、Solid、Preact、Vue、Svelte 与原生 TypeScript。
