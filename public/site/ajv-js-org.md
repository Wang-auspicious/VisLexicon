## Overview

Ajv 是一个高性能 JSON Schema 校验器，提供 JavaScript 库交付物，支持 JSON Schema draft-04/06/07/2019-09/2020-12 与 JSON Type Definition（RFC8927）多种模式，具备严格模式、独立校验代码生成、用户自定义关键字及异步校验等实际特性。
