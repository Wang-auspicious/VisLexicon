## Overview

Iconify 的 @iconify/utils 库文档页：一组被 Iconify 各图标组件复用的函数，用来解析 IconifyJSON 图标集、校验图标名与颜色、把图标导出成 SVG，也能压缩图标集体积。库用 TypeScript 写，ES module 和 CommonJS 都发。
