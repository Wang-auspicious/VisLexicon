## Overview

官方仓库里的 Svelte 预处理器，让 .svelte 文件直接写 PostCSS、SCSS、Less、Stylus、CoffeeScript、TypeScript 或 Pug。文档解释 Svelte 自带解析器只认 JavaScript、CSS 和它那套 HTML 语法，所以要靠 preprocess API 接别的语言。
