## Overview

Bezel UI 是一个 React 组件库，首页列出 100 个组件并按 General、Forms、Navigation、Animation、Sections 等类别筛选，可搜索组件。每个组件页提供预览与安装命令，例如 MagicRings 用 npx bezel-add add magic-rings 添加，DepthText 用 npx bezel-add add depth-text 添加；也可通过 npm i bezel-ui 安装。组件以可读 TypeScript 源码交付，供复制进项目。
