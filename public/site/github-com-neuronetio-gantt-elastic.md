## Overview

gantt-elastic 是开源的 JavaScript 甘特图组件，以 Vue 组件形式交付，用于在项目中嵌入可交互的任务时间线。页面标题与描述明确其支持响应式布局，并覆盖 Vue 甘特图与项目管理场景，便于开发者直接集成到前端应用。
