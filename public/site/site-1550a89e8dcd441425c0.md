## Overview

Scritto 是一个基于 Java 的原生文本动画库，以意大利语「书写」命名。它通过在元素值变化时仅对发生改变的字符进行动画处理，实现原地文本过渡效果：每个字符从旧字形滚动到新字形。核心交付物为 JavaScript 库，附带 GitHub Wiki 文档和在线 playground 演示环境，方便开发者直接查看与测试动画行为。
