## Overview

carbon-react-native 把 Carbon 设计系统搬到 React Native 上，给 RN 应用提供组件与共享模式，颜色 token 用 g10 做浅色主题、g100 做深色主题，排版 token 对齐 Carbon v11。它和 web 侧的 Carbon 分开维护，文档由 TypeScript 文件自动生成。
