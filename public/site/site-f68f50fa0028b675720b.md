## Overview

JSCharting 是面向 Web 开发的 JavaScript 图表库，提供超过 150 种图表类型与交互组件。交付物为可集成的 JS 图表组件及配套 API。实际特性包括：支持 SVG 与 Canvas 双渲染模式，内置数据标签、图例、工具提示和缩放平移等交互；提供响应式布局与主题定制，并兼容 React、Vue、Angular 等主流框架。
