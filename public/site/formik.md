## Overview

Formik 为 React 与 React Native 管理表单状态、校验和提交，文档提供字段、数组、错误提示与多步骤表单的接口。Overview 解释这三项职责，官方 Basic 页面把 Formik、Field、Form 代码与已渲染的姓名、邮件输入和提交按钮并列。可按自己的业务规则接入校验，原例的等待与 alert 不代表真实注册服务。
