## Overview

unplugin-vue-components 是一个用于 Vue 的按需组件自动导入插件，通过构建工具集成在编译阶段自动扫描并引入模板中使用的组件。其实际特性包括支持 Vue 2 与 Vue 3、兼容 Vite、Webpack、Rollup 等主流构建工具，并可自定义解析器以适配 UI 组件库。
