## Overview

framecn 提供基于 Editframe 的 React 视频组件，首页列出 Kinetic Text、Pill Karaoke 字幕、Album Carousel、Route Globe、Bar Chart 等可预览组件。可通过 shadcn CLI 安装到 components/framecn，在浏览器中调整文字、时序与颜色，并用 Editframe CLI 渲染为 MP4。
