## Overview

design-system-react 是美国消费者金融保护局（CFPB）设计系统的 React 实现，用 Storybook 组织组件文档，MIT 开源，并按 v2.0.3 发到 npm。给做政府或公共服务类产品、需要照 CFPB 设计系统出 React 界面的团队用。
