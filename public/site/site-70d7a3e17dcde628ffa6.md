## Overview

ogimagecn 提供用于生成 Open Graph 图片的 React 组件与区块，可通过 shadcn 命令安装，例如 pnpm dlx shadcn add @ogimagecn/avatar。站点包含 Avatar、Badge、Brand Mark、Divider、Grid Lines、Waveform 等组件文档，以及 Brand、Content 等区块，并提供 Playground 与 Scan 入口。
