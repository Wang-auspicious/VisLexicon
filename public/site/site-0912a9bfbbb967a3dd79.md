## Overview

Tabler Admin Template 提供基于 Bootstrap 的后台页面起点，产品页将响应式布局、界面组件和多个预制布局组合在一起。当前预览包含指标卡、趋势图与数据区；Buttons 页进一步展示图标位置、圆角形状、尺寸和动作按钮。可以先选后台布局再改用组件，具体开源版本、预编译包和其他产品套餐应分别核对。
