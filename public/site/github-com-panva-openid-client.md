## Overview

panva/openid-client 是面向 JavaScript 运行时的 OAuth 2 / OpenID Connect 客户端 API 库，交付可安装的客户端代码包。其特性包括支持多种 JavaScript 运行时环境，以及提供 OAuth 2 与 OpenID Connect 协议客户端实现，用于在应用中集成授权与身份认证流程。
