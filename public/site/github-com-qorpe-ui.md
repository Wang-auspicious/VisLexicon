## Overview

qorpe 家族控制台共用的 UI kit，把 ui-standard 的 token、原子组件和复合组件收在一处，供 Goldpath、Mockifyr 等几个内部控制台复用。仓库自带视觉回归基线：每个 demo 都留 light、dark、RTL 三套 Linux 截图。
