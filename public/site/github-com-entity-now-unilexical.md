## Overview

UniLexical 是一个基于 Lexical 构建的框架无关、Notion 风格块级富文本编辑器项目。其核心逻辑使用纯 TypeScript 实现，并为 Vue 3 和 React 提供轻量级封装，便于在不同前端框架中集成使用。该仓库主要交付编辑器核心代码与框架适配层，属于可嵌入的 UI 组件资源。
