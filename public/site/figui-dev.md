## Overview

FigUI 是一套为 Figma 插件开发提供的 Figma UI3 组件库，交付物为可复用的界面组件集合。实际特性包括支持 Button（含 Primary、Secondary、Destructive、Inverse、Success、Link、Ghost 等变体）和 Checkbox、Input、Slider、Select 等表单控件，页面按 Docs 分区组织各组件文档。
