## Overview

carlonicora/nextjs-jsonapi 是一个 Next.js 包，核心是符合 JSON:API 规范的客户端，服务端与客户端共用一套调用方式并自带缓存，同时随包附一份 shadcn/ui 组件库和配套的 Tailwind 配置、CSS 变量。适合后端已经是 JSON:API、又不想自己接 Next.js 数据层的项目。
