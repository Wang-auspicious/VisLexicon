## Overview

Gifski 是高质量 GIF 编码器，提供 Windows GUI 安装包、macOS App Store 与直接下载、CLI 二进制及 Rust cargo 安装方式。页面给出命令行示例，可将 video.mp4 转为 anim.gif，并说明用 --width、--fps、--quality 等参数调整尺寸、帧率与压缩，以控制 GIF 文件大小。
