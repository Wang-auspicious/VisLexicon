## Overview

BuilderTools 是一个面向设计与开发未来工具的策展展示站点，收录工具、资源与开源项目，并提供灵感与网站示例浏览。页面设有 Submit Tool 提交入口，并标注更新时间；站内可跳转至 Rare UI 等组件资源，Rare UI 提供 28+ 稀有独特组件，每个组件为单文件、可通过 shadcn CLI 或 MCP 添加。
