## Overview

Pin UI 提供可复用的 UI 组件库，涵盖输入控件、卡片小部件、音频媒体和列表选择器等类别，如 Search Card、Selection List、Desk Computer、Liquid Voice 和 File Box 等组件。页面支持明暗主题切换、组件搜索与提交设计入口，所有组件以代码形式交付，便于直接集成到前端项目中。
