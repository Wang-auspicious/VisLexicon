## Overview

react-native-system-navigation-bar 是一个 React Native 原生模块，用于控制 Android 系统导航栏、状态栏以及 iOS 主屏幕指示器。该库提供设置导航栏颜色、可见性、图标样式及全屏模式等 API，帮助开发者在跨平台应用中统一处理系统栏外观与交互行为。
