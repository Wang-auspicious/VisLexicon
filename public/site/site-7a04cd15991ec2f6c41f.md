## Overview

Nexvyn UI 是一个面向设计工程师的 React UI 库，提供可浏览的组件与区块目录，例如 Navigation Compass、Blossom Picker、Fader、Dia Text，以及 Banner、CTA、Footer、FAQ、Login 等区块。页面给出通过 shadcn CLI 安装组件的命令，并说明组件遵循 WAI-ARIA、带有动画，使用 TypeScript 与 Tailwind CSS 构建。
