## Overview

Theme UI 用主题对象和 sx 属性连接颜色、排版、布局与界面组件，便于在自己的项目中建立一致样式。Components 页面展示布局、网格、按钮和表单元素的范围；Button 实例把两个主题变体与对应 JSX 并置，文档另有 Color Modes、MDX 和 Theme Specification。它提供实现工具与组件起点，不是固定品牌视觉方案。
