## Overview

给 SvelteKit 做文档站的集成方案，作者自己给它的定位是「Svelte 版的 VitePress」：一个把 Markdown 转成 Svelte 组件的 Vite 插件，加上加载侧栏与 frontmatter 的 loader，再配一套仿 Tailwind 文档的预置主题。MIT 授权。
