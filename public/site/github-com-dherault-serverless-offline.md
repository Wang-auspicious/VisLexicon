## Overview

serverless-offline 是一个用于本地模拟 AWS Lambda 和 API Gateway 的开发工具，帮助开发者在本地调试 Serverless 项目。它支持在无网络部署的情况下运行和测试函数及 API 路由，主要交付物是一个可通过 npm 安装的命令行插件，实际特性包括本地模拟 API Gateway 请求和 Lambda 函数执行。
