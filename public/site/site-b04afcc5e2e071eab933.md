## Overview

Torph 是一个无依赖的文本变形动画组件，首页提供 npm 安装命令（npm i torph）以及 React、TypeScript、Vue、Svelte 的导入与用法示例，如 import { TextMorph } from 'torph/react' 和 <TextMorph>Hello world</TextMorph>。Examples 页展示数字、金额与长文本等变形示例，Showcase 页列出社区在界面中的实际使用。
