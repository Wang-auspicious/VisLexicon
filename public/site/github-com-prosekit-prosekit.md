## Overview

基于 ProseMirror 的无头富文本编辑器工具箱，同一套编辑逻辑可以挂到 React、Vue、Preact、Svelte、Solid 或纯 JavaScript 上。给要在自家产品里内嵌编辑器的开发者，样式完全不预置。
