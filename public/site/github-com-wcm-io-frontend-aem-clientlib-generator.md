## Overview

给 AEM 用的 Node 插件：按一份 clientlib 配置生成 ClientLib 的仓库节点文件、建好 Client Library 文件夹，再把静态资源同步过去，支持 JSON 与 FileVault XML 两种格式。

- 许可登记为 Apache-2.0（宽松 SPDX），再分发时须保留版权与许可声明。
