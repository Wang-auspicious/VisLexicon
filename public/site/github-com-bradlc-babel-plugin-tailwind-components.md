## Overview

一个 Babel 插件，让 styled-components 这类 CSS-in-JS 库能直接写 Tailwind 的类名——它把 tw 模板标签编译成对应的 CSS。官方推荐经 babel-plugin-macros 以 tailwind.macro 的别名引入。
