## Overview

一个 Next.js 单页应用，输入 GitHub 或 GitLab 用户名后抓公开贡献数据，画成五档色阶的贡献热力图，并给出总贡献数、当前连续天数、最长连续天数和单日最高。线上跑在 git-stats-pi-dun.vercel.app。
