## Overview

一个 Vue 组件，用来渲染单条 SVG path 形式的图标（比如 @mdi/js 里那种），在方形 viewBox 上提供翻转、旋转一类属性。原仓库名 JamesCoyle/vue-icon，现已转到 Pictogrammers 组织下。
