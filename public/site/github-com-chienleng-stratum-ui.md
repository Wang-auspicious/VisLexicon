## Overview

stratum-ui 是 Svelte 5 的 UI 与图表组件库：图表建在 LayerCake 加 runes 状态 store 上，交互组件建在 bits-ui 的 headless 原语上，整套主题只用 CSS 自定义属性，不依赖 Tailwind 也没有运行时样式库。MIT 开源，组件与图表分成 /ui 与 /charts 两个入口。
