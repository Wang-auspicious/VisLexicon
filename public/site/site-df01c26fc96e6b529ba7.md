## Overview

Dot Matrix 是一个围绕点阵加载动画的 React 组件库，首页列出 55+ 个加载器名称，并提供 Playground 与 Showcase 入口。用户可通过 shadcn registry 安装单个加载器，例如运行 npx shadcn@latest add @dotmatrix/dotm-square-3，也可复制代码作为本地组件自行修改。
