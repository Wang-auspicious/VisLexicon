## Overview

Material 是一个基于 Google Material Design 指南的 CSS 框架，提供可直接引入页面的样式交付物。其所有类名遵循 BEM 命名约定，并延续到 SCSS 与 CSS 变量命名中。使用者只需加载两个文件即可开始使用，框架强调便于开发，并包含无障碍相关说明。
