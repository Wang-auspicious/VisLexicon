## Overview

Protocol Launcher 是一个基于 Web 的协议启动器工具，用于在浏览器中生成并调用自定义 URL 协议链接。它提供协议模板配置与参数填充功能，支持快速生成可点击的协议跳转链接，便于测试或集成系统级协议调用。页面以静态网页形式交付，无需安装即可使用，适合开发调试与日常快速唤起本地应用。
