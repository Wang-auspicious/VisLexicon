## Overview

PrimeNG 是 Angular 界面组件套件，官网介绍主题预设、分层定制，以及表格、图表、对话框和菜单等控件。安装文档给出 primeng 与 @primeuix/themes 包，并说明 providePrimeNG 配置；Button 页完整展示 Reject、Accept 原按钮及 pButton 用法。可先按 Angular 版本与主题接入，再选具体控件；PrimeUI Pro 是另外的产品入口。
