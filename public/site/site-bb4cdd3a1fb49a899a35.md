## Overview

Illos.dev 提供 114 个动画 SVG 产品插画，分 Shader、HUD、Isometric 三种视觉系统，可按浅色/深色与品牌色筛选，免费 50 个可直接复制或下载。另提供面向 Claude Code、Cursor、Codex 等编码代理的 skill，用 npx -y illos setup 安装后按所选风格生成新插画；每幅插画可作 React 组件或纯 SVG 使用。
