## Overview

PrimeFlex 以 CSS 工具类实现栅格、Flexbox、间距、尺寸、文字和效果，可配合 Prime UI 库或静态页面。安装页列出版本搭配，Flex 页给出工具类与属性的对应；Initial 实例用两组不同长度的文字盒子说明收缩与基础尺寸。原站公告停止积极开发维护，采用前应核对目标版本及替代方案。
