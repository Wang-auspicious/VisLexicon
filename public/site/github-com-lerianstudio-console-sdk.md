## Overview

Midaz Console 的前端 SDK monorepo，装了三个包：仿 NestJS 的 Next.js 服务端框架 sindarian-server、建在 Radix UI 与 shadcn 上的 React 组件库 sindarian-ui，以及带 WCAG 门禁的 sindarian-tokens。
