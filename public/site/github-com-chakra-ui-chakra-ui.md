## Overview

Chakra UI 是一套用来快速搭 SaaS 产品的 React 组件系统，官方定位是 Build Accessible React Apps with Speed，无障碍是它的核心卖点之一。仓库以 MIT 开源，文档站是 chakra-ui.com。
