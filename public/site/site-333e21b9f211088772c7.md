## Overview

nuqs 是面向 React 的类型安全 URL 查询参数状态管理库。首页提供 useQueryState 与 parseAsInteger 的示例代码，并列出类型安全、内置解析器、历史控制、useQueryStates 等特性；文档站有 Installation 安装说明，Playground 提供 Basic counter、Batching、Hex colors、Pagination 等可运行示例。
