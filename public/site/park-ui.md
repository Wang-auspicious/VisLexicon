## Overview

Park UI 提供基于 Ark UI 与 Panda CSS 的现成界面组件，首页展示登录、支付和通知等组合方式，文档按按钮、数据展示与展开控件组织条目。Button 示例完整显示一个按钮及 CLI 添加命令，另有主题与安装入口。它为自建界面体系提供带样式的组件起点，项目展示里的订阅价格与商品卡片是示例内容。
