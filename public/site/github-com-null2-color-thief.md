## Overview

从图片里抓主色或一整条代表性色板的脚本：getColor(sourceImage) 给一个颜色，getPalette(sourceImage, 8) 给八色色板，靠 Javascript 与 canvas 标签取像素。仓库是 lokesh/color-thief 的 fork。
