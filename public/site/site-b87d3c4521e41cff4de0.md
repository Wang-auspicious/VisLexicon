## Overview

Ascii Studio 是一个在浏览器内把视频、图片或 GIF 转成 ASCII 字符动画的创作工具。上传素材后可调整列数、阈值、字符集、字体、字号与横纵间距，并生成可播放的 ASCII 视频；页面还提供导出完整 React 组件（内嵌 ASCII 帧）以及复制组件的入口。
