## Overview

ObsidianUI 提供可复制、可定制的 React 动画交互组件，页面列出 Active Sessions、Art Gallery、Discover Button、Draggable Marquee、Flip Text、Hover Image、Parallax Slider、Split Showcase、Status Bars、Text reel、v-prism 等组件，并含 Blocks 与 Templates 入口；文档区给出安装 Next.js、安装 Tailwind CSS、添加 utilities 与 CLI 的步骤。
