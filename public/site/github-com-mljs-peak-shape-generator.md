## Overview

mljs/peak-shape-generator 是一个 JavaScript 库，用于生成多种峰形（peak shapes），服务于科学数据可视化与信号处理场景。项目以代码形式交付，支持通过 npm 安装并在浏览器或 Node.js 环境中调用，提供可配置的峰形函数以匹配实验谱图或模拟数据。
