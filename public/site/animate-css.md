## Overview

Animate.css 把弹跳、淡入淡出、摇晃等 CSS 动画按用途分组，官网为条目提供复制类名的入口。官方仓库的使用文档说明 npm、Yarn 和样式导入方式；bounce.css 直接展示关键帧、位移和缓动代码。适合在现有元素上接入命名动画，并沿原始 CSS 调整效果，页面截图本身不证明动态过程或所有状态已测试。
