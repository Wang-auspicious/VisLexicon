## Overview

svrollbar 是一个用 Svelte 编写的自定义滚动条组件仓库。该项目提供可直接用于 Svelte 应用的滚动条 UI 实现，主要交付物为组件源码。其特点包括以 Svelte 框架为基础构建，以及提供可自定义外观的滚动条替代浏览器默认样式。
