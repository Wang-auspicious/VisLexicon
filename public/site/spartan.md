## Overview

spartan 把 Angular 控件的行为与可复制样式分开：官网说明先安装行为，再复制和定制样式，并连接组件与组合区块。Button 页的 Brain API 与安装命令说明行为入口，当前 Style Nova 示例完整显示文字按钮和图标按钮。示例已有视觉皮肤，但主交付仍围绕可自行组织样式的原语；站内示范支付与任务信息不是实际交易。
