## Overview

Raster 是一个极简 CSS 网格系统，交付物为可下载的 CSS 样式表与配套 HTML 标记示例。其核心特性是基于描述性 HTML 属性直接声明网格布局，而非编写语义化 CSS；通过 <r-grid> 与 <r-cell> 元素及 columns、span 等属性即可定义列数、跨列与合并区间，降低布局的样式编写成本。
