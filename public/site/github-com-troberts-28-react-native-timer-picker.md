## Overview

react-native-timer-picker 是一个面向 React Native 应用（Expo 与 Bare Workflow）的时长选择器组件，用于计时器、闹钟和时长输入场景。该组件提供简洁灵活的交互界面，并内置 iOS 风格触觉与音频反馈，便于开发者直接集成到移动端项目中实现时长选择功能。
