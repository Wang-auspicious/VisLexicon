## Overview

bytecodealliance/jco 是用于处理 WebAssembly Components 的 JavaScript 工具链。该仓库提供将 JavaScript 与 WebAssembly 组件模型结合的命令行工具和构建流程，支持组件编译、类型生成与运行集成，便于开发者把 JS 生态接入 WebAssembly 组件体系。
