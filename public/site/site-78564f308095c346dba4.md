## Overview

为 shadcn/ui 组件提供语义化声音反馈的组件库：首页展示 Button、Checkbox、Switch、Slider、Tabs、Toast、Dialog、Drawer、Accordion 等 24 个组件的试听与代码预览，可切换 Crisp 等声音包并触发 17 种声音提示；声音由 Web Audio API 在浏览器实时合成，无需音频文件，通过 shadcn CLI 安装后加 sound 属性即可使用。
