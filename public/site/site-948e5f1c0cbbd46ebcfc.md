## Overview

editorcn 提供基于 Tiptap、通过 shadcn 分发的 React 富文本编辑器组件，包含 Toolbar Editor 与 Block Editor 两类入口。首页给出 pnpm dlx shadcn add 安装命令，并展示文档中的工具栏图标替换、CSS 变量主题覆盖和自定义工具栏按钮等定制方式。
