## Overview

TDesign 是面向设计师和开发者的企业级设计体系，官网连接设计、基础组件、页面模板与资源。当前 React 组件概览按基础、布局等用途列出控件；Button 页把实际按钮与形状、尺寸、禁用和加载等配置放在同一示例区，并连接 API 与使用指南。可先了解体系范围，再沿对应技术入口查组件，版本与许可仍须单独核对。
