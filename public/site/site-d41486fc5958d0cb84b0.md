## Overview

OpenDesign 是一个开源设计 Agent 工作区：连接 Claude Code、Codex、Cursor 等本地编码 Agent，或使用自带 API Key，选择设计系统后用自然语言生成可运行的 HTML 原型、落地页、仪表盘、幻灯片与图形。生成后可直接移动、缩放元素、改文字与颜色，也可把团队评论交回 Agent 修订，并导出 HTML、PDF、PNG 或可编辑 PowerPoint。

## Do's and Don'ts

- 许可登记为 Apache-2.0（宽松 SPDX），再分发时须保留版权与许可声明。
- 许可原始记录 Apache-2.0：桌面应用以 Apache-2.0 开源。（证据：https://open-design.ai/）
