## Overview

Chakra UI 提供 React 组件系统，官网展示滑块、验证码输入和标签页，并给出安装入口。文档把布局与常用控件按用途组织，同时说明样式、主题和组合方式；Button 页将实际按钮、预览与代码选项、导入代码和 JSX 用法放在一起。适合在 React 产品中采用成套界面组件，并通过 token 和 recipe 为自己的系统定义样式。
