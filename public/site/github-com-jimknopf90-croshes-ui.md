## Overview

德语 README 的 React 加 Tailwind 设计系统，被自家两个产品线在用：AlpakaPro 的 breeding-ui、admin-ui 和 Alpaca-Store 的 store-ui、store-manager-ui。组件里有 DatePicker、Table、Toast、Tabs，消费者要自己把它的 tailwind preset 引进来。
