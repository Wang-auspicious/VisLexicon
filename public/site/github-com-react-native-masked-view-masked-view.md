## Overview

React Native 的蒙版组件：把一段 JSX 当遮罩去裁切另一段内容，做渐变文字或圆形头像不用自己写原生代码。仓库已从 react-native-masked-view 迁到 callstack 名下，iOS、Android、Web 三端都支持。
