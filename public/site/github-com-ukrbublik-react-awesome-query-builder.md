## Overview

React 的查询与筛选条件构造器，把 AND/OR 规则拼成树，控件皮肤可以换成 Ant Design、Material-UI、Bootstrap 或 Fluent UI。条件树能存成配置从服务端加载，仓库里也有从 SQL 导入的处理。
