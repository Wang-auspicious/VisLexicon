## Overview

React Select 为 React 提供可定制的选择输入，首页给出单选与多选示例，文档按样式、组件、异步加载与可创建选项分开。Async 页面说明回调和 Promise 两种载入方法；Creatable 展示多个选择控件与 onCreateOption 配置说明。高级例子模拟后台等待，采用时仍需接入自己的数据服务。
