## Overview

carbon-charts 是 IBM Carbon 团队做的数据可视化框架，用 D3 与 TypeScript 写成，一套代码覆盖 vanilla JavaScript、Svelte、React、Vue.js 和 Angular 五个方向，README 自称包含 26 种图表。仓库以 Apache-2.0 开源，由 carbon-design-system 组织维护。
