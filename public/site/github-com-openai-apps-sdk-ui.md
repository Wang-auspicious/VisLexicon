## Overview

OpenAI 官方的 ChatGPT Apps 设计系统：一套 Tailwind 4 设计 token、一套建在 Radix 原语上的 React 组件库，再加暗色模式与响应式工具。用来让 ChatGPT 里的 app 界面彼此一致。
