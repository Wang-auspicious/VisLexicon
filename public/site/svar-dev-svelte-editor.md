## Overview

SVAR 的 Svelte 表单编辑器组件：把页面上任意 UI 元素或数据行接上一个可弹窗、可侧栏展开的编辑表单，带输入控件、校验与保存策略配置。MIT 授权，可在编辑器内复用 SVAR Core 的表单控件。
