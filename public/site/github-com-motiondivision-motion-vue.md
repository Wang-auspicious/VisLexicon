## Overview

Vue 版的 Motion 动画库，用 motion.div 加 :animate="{ x: 100 }" 这种声明式写法做弹簧、关键帧、布局动画、手势与滚动动画，引擎把 JavaScript 动画和原生浏览器 API 混着用。给写 Vue 的前端。
