## Overview

Cline 是 cline.bot 做的自主编码 agent，可以当 SDK、IDE 扩展或命令行助手用，会自己跨项目改代码、跑 bash 命令，并在 Plan 与 Act 两种模式间切换。仓库 Apache-2.0 开源，68.1k stars，支持接 MCP 服务器与 Slack、Telegram、Discord。
