## Overview

SVAR 的 React 数据筛选组件库，由四个 TypeScript 组件组成：完整查询构建器 FilterBuilder、支持结构化语法与自然语言的 FilterQuery、内联输入条 FilterBar、单条规则编辑器 FilterEditor。MIT 授权。
