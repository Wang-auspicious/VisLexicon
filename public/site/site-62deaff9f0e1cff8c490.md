## Overview

Rolling Number 是一个通过 npm 安装的滚动数字动画组件，包名为 @kitlangton/rolling-number，提供 bun、npm、pnpm 安装命令。页面用商品价格、营收、点赞数、团队套餐、BigInt 事件 ID 等示例展示数字滚动效果，并支持上一项/下一项切换。
