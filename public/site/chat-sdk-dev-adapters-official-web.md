## Overview

这是 Chat SDK 官方 Web 适配器的文档页，它让同一个 bot handler 除了 Slack、Teams、Discord 之外还能在浏览器里开一个聊天界面。协议对齐 AI SDK 的 UI message stream，所以 React、Vue、Svelte 的 useChat 可以直接用。
