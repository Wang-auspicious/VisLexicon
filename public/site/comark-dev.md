## Overview

一个 JavaScript 库，把 Markdown 解析成 MarkdownDocument 之后，交给 HTML、ANSI、Angular、React、Vue、Svelte 六种渲染器输出。主要解决模型流式吐字时半截粗体、代码块没闭合、每来一个 token 布局就跳的问题。
