## Overview

HextaUI 提供基于 shadcn/ui 与 Base UI 的 React 组件、Hooks 和工具，可通过 shadcn CLI 将源码复制进项目；组件页按表单、浮层、数据展示、布局、反馈、聊天 UI 等分类浏览，并附实时状态文档。另有 Pro 区块，如 Chat Thread、Prompt Input、Voice Mode、Agent Todos，提供流式、工具调用与语音等 AI 聊天界面。
