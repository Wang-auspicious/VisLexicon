## Overview

mcpcn 提供面向 MCP Apps 的 React UI 组件与区块，首页展示 Amount Input、Message Bubble、Status Badge、Stat Card 等示例，并给出通过 shadcn 安装的命令（如 pnpm dlx shadcn add @mcpcn/amount-input）。文档区按 Form、Payment、List、Selection、Status 等分组列出 Contact Form、Date & Time Picker、Order Confirm、Product List、Table、Option List、Tag Select、Quick Reply、Progress Steps 等区块，可浏览并复制给 agent 的 prompt。
